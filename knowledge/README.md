# AI 참고 문서 폴더

관리 기준일: 2026-11-06. 운영자용 실행·배포 문서는 [Groq 가이드](../docs/GROQ_CHAT.md), 코드 흐름은 [아키텍처](../docs/ARCHITECTURE.md#8-ai-채팅과-문서-검색)를 참고하세요. 이 안내 문서 자체는 AI 검색 대상이 아닙니다.

이 폴더에 운영자가 확정한 공개 안내 문서를 넣으면 AI가 질문과 관련된 구간을 찾아 답변의 참고 자료로 사용합니다. 이 README와 `.example` 파일은 검색하지 않습니다. 현재 구현된 화면의 이용 방법을 담은 `shop-guide.md`가 기본으로 제공됩니다. 확정된 환불 정책은 임의로 만들지 않았습니다.

## 등록 방법

1. `refund-policy.md`, `shipping.md`, `faq.txt` 같은 이름으로 **UTF-8 Markdown(.md) 또는 텍스트(.txt)** 파일을 이 폴더에 저장하세요. 하위 폴더도 검색합니다.
2. 문서에는 정책 제목, 적용일, 대상, 조건, 예외, 비용, 문의 방법 등 실제 승인된 사실을 명확히 적으세요. 날짜·금액·연락처를 임의로 채우지 마세요.
3. `refund-policy.md.example`은 작성 틀입니다. 복사해 `.example`을 제거하고 모든 대괄호 안내를 실제 승인 내용으로 바꾼 뒤 사용하세요. 초안은 `.example` 확장자를 유지해 검색에서 제외하세요.
4. 파일명과 내용에 '환불', '반품', '배송'처럼 사용자가 물어볼 단어를 적으면 검색하기 쉽습니다. 한 문서가 길다면 주제별로 나누세요.
5. 아래 명령으로 확인하세요. 검색 확인은 Groq를 호출하거나 무료 할당량을 사용하지 않습니다.

```powershell
Set-Location 'C:\AI4\Day12-Demo\project'
$env:PYTHONIOENCODING='utf-8'
.\.venv\Scripts\python.exe -m flask --app wsgi:application check-chat-docs
.\.venv\Scripts\python.exe -m flask --app wsgi:application check-chat-docs --query '환불은 언제까지 가능한가요?'
```

최초 코드 업데이트 후에는 Flask 재시작/PythonAnywhere Web Reload를 하세요. 이후 문서의 추가·수정·삭제는 다음 질문부터 다시 읽어 반영합니다. 과거 대화의 영향을 없애려면 새 대화로 시험하세요. PythonAnywhere에서도 프로젝트의 `knowledge/` 폴더를 업로드해야 합니다.

## 검색과 답변 범위

동작 흐름은 `질문 → 전용 폴더 검색 → 관련 구간·출처를 Groq에 전달 → 답변과 참고 문서 표시`입니다. 문서를 모델에 재학습시키는 방식이 아니며, 모델 파일을 내려받거나 임베딩 서비스를 설치하지 않습니다.

- 별도 벡터 DB·임베딩 API 없이 질문 단어와 한국어 두 글자 조합으로 검색합니다. 최근 사용자 질문은 후속 질문의 맥락을 보완합니다. 동의어·모호한 질문은 검색하지 못할 수 있습니다.
- 최대 50개 파일, 파일당 128KiB, 전체 1MiB를 읽습니다. 파일당 내용을 약 1,200자 구간으로 나누고 관련 구간 최대 4개를 모델에 전달합니다. 무조건 모든 문서를 전달하지 않습니다.
- `.md`/`.txt` 외 PDF·Word·이미지는 읽지 않습니다. 공개할 본문을 먼저 UTF-8 문서로 변환해 넣으세요. 숨김 경로, `README.md`, 심볼릭 링크, 빈 파일은 제외합니다. 인코딩 오류·용량 제한으로 건너뛴 파일은 점검 명령에 표시합니다.
- 문서 기반 설명에는 `[문서1]` 같은 출처 ID를 붙이도록 지시합니다. 답변 아래 '검색된 참고 문서'에는 모델에 전달된 파일명과 행 범위가 표시됩니다. 이 목록 자체가 답변의 모든 문장이 검증됐다는 뜻은 아닙니다.
- 현재 가격·재고는 DB 상품 정보가 우선입니다. 정책은 등록 문서를 참고하며, 없는 정보는 확인할 수 없다고 안내합니다. 충돌하는 문서는 하나만 남기거나 운영자가 적용 조건을 명시하세요.
- 문서는 행동 지시가 아닌 참고 데이터로 취급합니다. 시스템 지시문은 `app/services/chat.py`의 `SYSTEM_PROMPT`, 검색 구현과 제한은 `app/services/knowledge.py`에 있습니다. 프롬프트만으로 오답·지시문 우회를 완전히 막는 것은 아닙니다.

## 넣을 수 있는 정보

문서의 관련 내용은 **Groq 외부 API로 전송**되고 파일명·행 범위가 방문자에게 표시됩니다. 고객에게 공개해도 되는 안내만 넣으세요. 비밀번호, API 키, 내부 운영 문서, 회원·주문·주소 정보는 넣지 마세요. 일반 프로젝트 `docs/`나 `.env`는 이 검색 기능에서 읽지 않습니다. 폴더 자체를 정적 파일 URL로 공개하지 않습니다.

## 등록 후 점검

| 결과 | 확인 방법 |
| --- | --- |
| 기본 상태 | 읽기 성공 파일은 shop-guide.md 1개; 환불 검색 결과는 0개 |
| 추가한 문서가 목록에 없음 | 확장자·UTF-8·파일 크기·숨김 경로·README 또는 .example 이름 확인 |
| 읽기는 성공하지만 검색 결과가 없음 | 질문과 파일명·본문의 키워드가 맞는지 확인 |
| 과거 내용으로 대답 | 실제 배포 서버의 파일 내용·경로를 확인하고 새 대화에서 재질문 |
| 근거와 답변이 다름 | 표시된 파일·행 범위를 읽고 실제 정책과 비교; 검색된 후보가 곧 검증된 답변은 아님 |

실제 정책 문서를 삭제하면 이후 검색에서 제외됩니다. 단, 이미 브라우저 화면에 표시된 답변이 자동 삭제되거나 Groq로 전송한 과거 요청이 회수되는 것은 아닙니다. 정책 적용일과 예외를 명확히 적고, 오래된 중복 정책은 정리하세요.
